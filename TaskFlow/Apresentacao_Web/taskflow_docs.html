Divisão de Responsabilidades

O projeto TaskFlow está dividido entre duas pessoas com escopo bem definido para evitar conflitos de código.

PA
Pessoa A
Backend · Core · Estruturas de Dados
Responsável pelo projeto TaskFlow.Domain: implementação das estruturas de dados (Grafo, FilaPrioridade, PilhaUndo) e regras de negócio.
GrafoDependencias FilaPrioridade PilhaUndo Entidades de Domínio
PB
Pessoa B
Interface · UI/UX · Navegação · Integração
Responsável pelo projeto TaskFlow.App: telas do sistema (Views), loop de navegação, mock services e contratos de integração com o backend da Pessoa A.
MenuNavigator Views MockServices ITaskFlowService

Organização modular do projeto TaskFlow.App, seguindo separação de responsabilidades (SRP) e princípio de inversão de dependência (DIP).

Fluxo de Navegação — MenuNavigator

O MenuNavigator.cs centraliza o loop principal e roteia para a view correspondente, eliminando switch-case no Main.

1
Inicialização — Program.cs
O Main() instancia o MenuNavigator e chama Iniciar(). Toda a lógica de navegação fica encapsulada no navigator.
Program.cs
2
Cabeçalho + Menu Principal
Loop while renderiza o cabeçalho colorido e as 7 opções do menu. Input lido com Console.ReadLine(), tratamento de null com string?.
Navigation/MenuNavigator.cs
3
ProcessarOpcao() — Roteamento
Switch-case processa a opção e invoca o método estático Renderizar() da view correspondente. Opção inválida exibe mensagem em vermelho sem quebrar o loop.
Navigation/MenuNavigator.cs · Views/*View.cs
4
Views — Renderização via MockService
Cada view recebe dados via ITaskFlowService. Na Fase 1, o TaskFlowMockService provê dados estáticos. Na integração com a Pessoa A, basta trocar a implementação sem alterar as views.
Views/DashboardView.cs · KanbanView.cs · FinanceiroView.cs · GrafoDependenciasView.cs
5
Pausa + Retorno ao Menu
Após cada view, Pausar() aguarda Enter antes de limpar o console e reexibir o menu, garantindo UX fluida sem travamentos.
Navigation/MenuNavigator.cs · Pausar()

Como Executar o Projeto
Pré-requisitos: .NET 8.0 SDK instalado. Verificar com dotnet --version no terminal.
Opção 1 — Terminal (PowerShell)
PowerShell 
# Navegar até a pasta Fase1_PessoaB
cd "C:\Users\Fabrício\Documents\FACULDADE___UCL\Projeto AED2\Fase1_PessoaB"

# Executar a aplicação
dotnet run --project TaskFlow.App\TaskFlow.App.csproj

# Ou compilar e gerar o executável
dotnet build TaskFlow.sln
Opção 2 — Visual Studio / VS Code
1. Abrir o arquivo TaskFlow.sln no Visual Studio 2022 ou VS Code
2. Definir TaskFlow.App como projeto de inicialização
3. Pressionar F5 para Debug ou Ctrl+F5 para executar sem debug
